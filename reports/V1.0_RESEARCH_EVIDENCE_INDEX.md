## 3. Baseline-versus-segmented evidence

V0.6 compared three permissive-baseline rounds against
three segmented-policy rounds using six scenarios.

The permissive baseline produced 12 observations of
reachability for four flows disallowed by the target
segmented policy. These were expected control outcomes,
not failures of the permissive baseline.

The segmented condition blocked those 12/12 attempts.
The two approved flows succeeded in all 6/6 executions.

Within this defined test matrix:
- False allows: 0/12.
- False denies: 0/6.

These findings do not estimate real-world error rates.

## 4. Performance evidence

V0.7 measured TCP connection timing and bounded throughput.

- Employee-to-Application median connection timing:
  0.40397 ms baseline; 0.41528 ms segmented.
- Application-to-Data median connection timing:
  0.38466 ms baseline; 0.41259 ms segmented.
- Receiver throughput measurements were approximately
  50.115 Mbit/s under the selected bounded test load.
- Single deployment and teardown measurements:
  0.64535 s and 0.25646 s respectively.

These measurements are descriptive. They do not
establish statistical significance, capacity limits
or generalizable performance overhead.

## 6. Runtime decision and research boundaries

The demonstrated runtime is Windows 11 with
WSL2 Ubuntu 24.04 and four Linux network namespaces.

The choice supports lightweight experiments under
the available hardware resource constraints.

The initial research proposal discussed comparing
WSL2 with an Ubuntu Server virtual machine.
A complete, equivalent, independently validated
cross-runtime experiment has not been established.

The deployment uses temporary project-owned veth
creation in the default Linux network namespace,
followed by movement into isolated namespaces.
This must not be described as zero host-network
interaction.

The nftables experiment enforces rules principally
through the gateway forwarding hook.

Identity-based authorization, endpoint posture,
continuous trust evaluation, IPv6 coverage,
comprehensive anti-spoofing, abnormal crash recovery
and production security readiness are not demonstrated.
